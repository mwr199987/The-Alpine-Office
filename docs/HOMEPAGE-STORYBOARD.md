# Homepage storyboard

The current review design refines the earlier cinematic draft. See BRAND-REFINEMENT.md for the audit and design system.

| Scene | Purpose | Composition and behaviour |
| --- | --- | --- |
| Arrival | Establish desire and identity | Retained twilight hero; asymmetric regular/italic title; portrait mobile crop. Light desktop movement, native scrolling. |
| Possibility | Express breadth without a catalogue | Two landscape fragments at the margins, large central type. Shortened sticky sequence; ordinary flow under reduced motion. |
| Reduction | Express selective judgement | “We don’t.” on quiet ivory. Reduced dwell and no additional images. |
| Place | Move from appearance to practical suitability | Existing silent chalet concept film; controlled playback. Mobile requires explicit Play. |
| Week | Make timing part of the recommendation | Village image beside editorial copy on school dates, altitude, light and resort rhythm. |
| Details | Express remembered human preferences | Existing morning concept; short practical examples. |
| Office | Explain the service | Private clients, families and assistants; chalet/hotel sourcing, itinerary and arrangements. |
| Office note | Demonstrate reasoning | Clearly labelled illustration: slope-side prestige versus a family's actual routes and needs. Reference, margin, reasoning and conclusion. |
| Founder | Supply personal accountability | Retained real founder portrait and existing biography; typographic name rather than a fabricated signature. |
| Memory | Explain continuity | Retained remembered arrangements and feedback, carried into the next season. |
| Alps | Preserve all-season relevance | Summer principal image; four native country disclosures. Additional panorama removed. |
| Introduction | Invite a natural next step | Plain charcoal, quiet Office device, one invitation. Repeated hero removed. |
| Enquiry | A clear private introduction | Native modal, explicit preview status, predictable Tab cycle, preserved inputs and strict acceptance handling. No live endpoint. |

All core page copy is visible without JavaScript. Body copy is continuously visible on mobile; optional desktop reveals are disabled by reduced-motion preference. The media register distinguishes atmospheric concepts from the founder photograph and inherited imagery.
